# Team Charter & Governance Agreement

## Team Principles
1. **Academic Integrity:** All code, analysis, and documentation must represent original work. All external libraries, documentation, and reference materials must be explicitly cited[cite: 1, 2].
2. **Reproducibility:** Every member must verify that notebooks run top-to-bottom on a fresh `.venv` environment using fixed random seeds before committing changes[cite: 1, 2].
3. **Equal Contribution:** Tasks are tracked transparently. All members must be prepared to present and explain any code section during the final video presentation[cite: 1].

## Code Quality Standards
* Python code must follow PEP 8 styling conventions.
* Notebook outputs must be saved with rendered visualizations before submission[cite: 1, 2].
* Git commit messages must be descriptive (e.g., `feat(prep): add frequency encoding for service column`).
